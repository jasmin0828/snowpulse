# SnowPulse Gate 4 — Resilience Report

## Runtime source contract

SnowPulse has exactly three runtime source states:

- `LIVE DATA`: the official Avalanche Metrics API returned a complete,
  comparable result for the frozen four-chain universe and the deterministic
  intelligence pipeline completed.
- `SNAPSHOT DATA`: live retrieval failed or produced an unusable result, and a
  schema-valid snapshot previously generated from real Avalanche API output
  was available.
- `UNAVAILABLE`: live retrieval was unusable and no schema-valid real snapshot
  was available. Ranking is withheld.

The runtime never converts a failed request into mock values and never labels
snapshot values as live.

## Snapshot provenance

The committed `data/snapshot.json` was generated by:

```text
npm run snapshot
```

The command completed a successful live run through the official Avalanche
Metrics API, then serialized the resulting typed intelligence payload. It did
not use hand-written or test fixture values.

- `schemaVersion`: `1`
- `source`: `AVALANCHE_METRICS_API`
- `generatedAt`: `2026-09-06T07:41:13.589Z`
- frozen universe: Beam `4337`, Dexalot `432204`, Blaze `46975`, Gunzilla
  `43419`
- selected stable bucket: `2026-09-03T00:00:00.000Z`
- latest available bucket: `2026-09-04T00:00:00.000Z`
- latest available state: `PROVISIONAL`
- fallback selection: `true`

The snapshot contains the per-chain metric evidence, Activity Score, status,
confidence, deterministic explanation, next question, freshness metadata, and
the derived ranking required to reproduce the dashboard without the API.

## Fault-path validation

Focused resilience tests cover all three source paths:

1. A successful live loader returns `LIVE DATA`.
2. A simulated live outage with the checked-in schema-valid snapshot returns
   `SNAPSHOT DATA`.
3. A simulated live outage with no valid snapshot returns `UNAVAILABLE` and an
   empty ranking payload.

The snapshot parser rejects a changed source marker, malformed payloads,
non-frozen chain universes, incomplete signals, uncertain freshness, and
withheld rankings. Snapshot fallback therefore remains limited to a complete,
previously captured real Avalanche result.

## Production boundary

Gate 4 adds resilience only. It does not add AI, token prices, wallet
connection, smart contracts, a database, additional chains, or new scoring
logic.
