# SnowPulse

Avalanche L1 Activity Intelligence.

SnowPulse is a minimal Avalanche Builder Day project foundation. The current
version is intentionally limited to a public, deployable landing page.

## Local development

```bash
npm install
npm run dev
```

Open <http://localhost:3000> in a browser.

## Production build

```bash
npm install
npm run build
npm start
```
